# Cursor Rules – Frontend (Next.js)

Este diretório consolida regras específicas para o front. Use junto com `front/.codex/rules.md` e com os contratos do backend em `api/.codex/rules.md`.

## Como Usar
- Arquivos Next.js/React (`.jsx`, `.tsx`, `.js`, `.ts`): aplicar `cursor_rules_nextjs.md`.
- Regras gerais do agente: `front/.codex/codex_rules.md`.
- Contratos de API: `api/.codex/rules.md`.

## Prioridade
- Preferir contratos e padrões já existentes no projeto.
- Quando houver conflito, seguir o contrato público do backend e o estilo atual do front.
